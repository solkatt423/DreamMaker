# Dream Maker 原型

黑色背景；1366×768 逻辑画布，上方 576 像素为游戏区，下方 192 像素为贴纸库。关卡宽 4098 像素，横向跟随人物；人物到画面约三分之一处后镜头前移，终点附近停止。

## 试玩

如 GameMaker IDE 已打开这个工程，请重新加载磁盘上的工程后再运行，避免旧编辑器内容覆盖新文件。F5 运行。

- 点击纸条上的 begin 或按 Enter 开始。开始前不能取贴纸，起点提供约 2.8 秒安全路程。
- 鼠标左键从下方拖取贴纸，松手放置；右键或拖回库取消。
- 地面：从上方接住角色。仅拖动预览时显示承接面。
- 弹簧：从上方接触弹起，保持水平速度。
- 吊钩：人物从挂点左下方进入吸附范围，沿弧线向右摆；到右侧 40 度自动释放，无需按空格。低速入钩会补足摆荡能量，释放后继承切线速度；离开吸附范围前不会被同一个吊钩重新抓住。
- Esc / P 暂停或恢复，也可点击右上暂停图形。暂停期间不能铺路。
- R 清场重试；失败或通关后可点击回转箭头。重试回到 begin 和空道路。
- 走到末段出现的心脏出口通关；掉到下方贴纸库边界判负。

三叠贴纸无限供给，各类外观独立洗牌，用完一轮再洗；取消不换图，重试保留初始顺序。预先生成下一袋，保证露出的下一张与实际抽取一致。已放置贴纸暂不支持重新移动、缩放和旋转。角色为约 72 像素高的临时剪纸人形，动作采用分段姿势；以后可替换正式素材。界面唯一文字为 begin，贴纸库使用真实图案的错位与倾斜堆叠。

## 实现位置

- `scripts/scr_dream/scr_dream.gml`：DreamGame 状态、库存、拖放、固定步长运动、碰撞与显示方法。
- `objects/obj_player`：房间入口，Create/Step/Draw GUI/Clean Up 调用游戏结构。
- `datafiles/stickers`：复制的 17 张原始透明 PNG，运行时加载，退出时释放。原始 Pictures/Dream 文件未修改。
- `tests/dream_v2_regression.gml`：新版独立回归检查，不注册为正式游戏资源；已替换旧版测试脚本。

运动参数集中在构造函数开头；角色图像替换入口是 `draw_player`，动作状态为 run/rise/fall/swing，落地通过 land 计时器表现。脚底是统一位置基准。地面与弹簧使用按图案宽度确定的水平承接面；吊钩使用中心挂点，后续可增加每张图片的手工锚点配置。

## 验证记录

Windows VM / runtime 2026.0.0.23 编译通过。新版在真实游戏运行时执行 70 项断言，覆盖开始前与暂停时禁止拿取、洗牌与跨袋预览一致、取消不消耗、滚动中鼠标坐标转换、贴纸固定在关卡坐标、起点安全时间、失败重置、高速落地、弹簧高度、三组不同入钩条件自动释放并落到承接平台，以及完整三屏路线通关和镜头末端限制；结果 FAILURES=0。已检查游戏内部生成的开场和滚屏场景截图。

测试执行方式：在临时测试版本中把测试函数加入脚本，在第 3 帧调用 DreamRegression(game)，使用 screen_save 保存渲染结果；验证结束后已撤回测试入口，正常版本不会自动测试或退出。新版测试输出保存在 `.gms_mcp/dream-v2-tests.txt`，截图为 `.gms_mcp/dream-v2-initial.png` 和 `.gms_mcp/dream-v2-scrolled.png`。滚屏截图使用专门布置的检查场景；正常开局为空白路线。

当前是三屏长的自由搭路原型，未制作正式新手教学、声音与多关卡内容。
